# Market Surveillance – Unusual Trading Activity Detection

## Project Overview
An Excel-based financial data analysis project designed to identify unusual stock trading activity using simulated market data.

## Objectives
- Analyse stock trading volume and closing prices.
- Calculate rolling five-day average trading volume.
- Identify unusual volume spikes using predefined thresholds.
- Monitor daily stock price movements.
- Visualise trading activity through charts and a dashboard.

## Tools Used
- Microsoft Excel
- AVERAGE and IF functions
- Rolling averages and volume ratios
- Percentage price-change calculations
- Rule-based alert logic
- Data visualisation

## Methodology
1. Prepared simulated stock trading data covering 15 trading days.
2. Calculated the average trading volume over the previous five trading days.
3. Compared current trading volume against the rolling average.
4. Flagged observations with volume at least twice the baseline.
5. Visualised trading volume and price movements.

## Key Findings
Two observations exceeded the predefined trading-volume threshold and were flagged for further review.

## Limitations
This is an educational prototype using simulated data. A flagged observation indicates unusual trading volume and does not establish insider trading or market manipulation.

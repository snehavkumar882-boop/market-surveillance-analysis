MARKET SURVEILLANCE — POWER BI DAX MEASURES
Model table name assumed: Market_Data
Import Market_Surveillance_Analysis.xlsx > Market_Data sheet/table.
If Power BI assigns a different table name, replace Market_Data in the formulas.

1) Trading Days =
COUNTROWS(Market_Data)

2) Evaluated Days =
CALCULATE(
    COUNTROWS(Market_Data),
    Market_Data[Surveillance_Flag] IN { "REVIEW", "NORMAL" }
)

3) Review Alerts =
CALCULATE(
    COUNTROWS(Market_Data),
    Market_Data[Surveillance_Flag] = "REVIEW"
)

4) Normal Days =
CALCULATE(
    COUNTROWS(Market_Data),
    Market_Data[Surveillance_Flag] = "NORMAL"
)

5) Baseline Days =
CALCULATE(
    COUNTROWS(Market_Data),
    Market_Data[Surveillance_Flag] = "BASELINE"
)

6) Alert Rate =
DIVIDE([Review Alerts], [Evaluated Days], 0)

7) Total Trading Volume =
SUM(Market_Data[Trading_Volume])

8) Average Trading Volume =
AVERAGE(Market_Data[Trading_Volume])

9) Highest Trading Volume =
MAX(Market_Data[Trading_Volume])

10) Average Volume Ratio =
AVERAGEX(
    FILTER(Market_Data, Market_Data[Surveillance_Flag] IN { "REVIEW", "NORMAL" }),
    Market_Data[Volume_Ratio]
)

11) Maximum Volume Ratio =
MAX(Market_Data[Volume_Ratio])

12) Average Closing Price =
AVERAGE(Market_Data[Closing_Price])

13) Review Volume =
CALCULATE(
    SUM(Market_Data[Trading_Volume]),
    Market_Data[Surveillance_Flag] = "REVIEW"
)

FORMATTING
- Alert Rate: Percentage, 1 decimal place.
- Average Volume Ratio and Maximum Volume Ratio: Decimal number, 2 decimal places.
- Trading volume: Whole number with thousands separator.
- Closing price: Currency or decimal, depending on the intended presentation.
